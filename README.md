## 🎬 1. Visual Identity & Cinematic Theme

This portfolio is engineered with a high-impact, video-editor showreel aesthetic:
- **Palette**: Deep Void (`#050505`), Surface (`#0f0f10`), Crimson (`#d90429`), Deep Red (`#8d0b1c`), Neon Glow (`#ff2a45`), Accent Yellow (`#ffe600`), Text (`#f5f5f5`), Muted (`#9a9a9a`).
- **Typography**: Anton (headings, uppercase, tight tracking), Inter (body) via Google Fonts.
- **Atmospheric Effects**: Red neon text glows, moving diagonal red light streaks, 12px glassmorphism cards, subtle film-grain overlay, and desktop custom cursor with trailing glow.

## ⚡ 3. Quickstart & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/hariprasath-tech/Portfolio.git
cd Portfolio/frontend

# 2. Install dependencies
npm install

# 3. Start the local development server
npm run dev
# -> Opens http://localhost:5173/

# 4. Create production build
npm run build
```

## 📝 4. How to Edit Portfolio Content

All copy, stats, links, projects, and video items live in a single centralized file:
👉 `frontend/src/data/content.ts`

- **Personal Info & Bio**: Update `content.personal` (roles, headline, bio, stats, social links).
- **Projects**: Update `content.projects` (add/edit titles, problem, solution, tech stack, github links).
- **Video Showcase**: Update `content.videoShowcase` (add/edit reels, brand promos, event videos).
- **Experience**: Update `content.experience` (roles, companies, responsibilities).
- **Leadership & Milestones**: Update `content.leadershipAchievements`.
- **Beyond Code**: Update `content.beyondCode`.

## 🚀 5. Deployment Options

### Vercel
1. Push this repository to GitHub.
2. Import project into [Vercel](https://vercel.com/).
3. Set **Root Directory** to `frontend`.
4. Deploy — zero extra configuration required.

### Netlify
1. Connect repository in [Netlify](https://www.netlify.com/).
2. Base directory: `frontend`.
3. Build command: `npm run build`.
4. Publish directory: `dist`.
