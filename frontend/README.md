# HARI PRASATH S – Portfolio Frontend Client

Production-quality personal developer portfolio frontend architected with:
- **Vite + React 19 + TypeScript**
- **Tailwind CSS v4**
- **Framer Motion + GSAP (ScrollTrigger) + Lenis Smooth Scroll**
- **Lucide Icons & Anton / Inter Google Fonts**

For complete setup, content editing instructions, and architecture guide, please refer to the main repository [README.md](../README.md).

### Scripts
- `npm run dev`: Start local development server on `http://localhost:5173/`
- `npm run build`: Typecheck with `tsc -b` and compile production bundle with `vite build`
- `npm run preview`: Preview production build locally
